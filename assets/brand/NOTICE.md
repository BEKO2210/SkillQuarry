# Third-party marks

The three marks in this directory are outlines taken from
[simple-icons](https://github.com/simple-icons/simple-icons), which publishes
its icon files under **CC0 1.0** (public domain dedication). Each file was
reduced to a single path and set to `fill: currentColor` so the site can draw it
in its own colour without recolouring anyone's official artwork.

| File | Mark |
|---|---|
| `github.svg` | GitHub |
| `rust.svg` | Rust |
| `python.svg` | Python |

**The trademarks are not ours and are not CC0.** They belong to GitHub, Inc.,
the Rust Foundation and the Python Software Foundation respectively. They appear
on this site for one purpose: to name the tools this project is built on.

- No sponsorship, partnership, affiliation or endorsement is claimed or implied,
  and the page says so next to the marks.
- The marks are not used in the project's own logo, favicon or product name.
- Each mark links to the project it names.

If a rights holder would rather not appear here, remove the entry from
`BUILT_WITH` in `tools/build_site.py`, delete the file, and regenerate the site.
