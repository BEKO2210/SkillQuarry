# Emberflow

A movement about heat finding its way through stone.

## Principles

1. **Heat follows weakness.** Every stroke moves along a noise field, the way
   warmth follows the fracture it can widen — direction is never chosen, only
   discovered. (`noise(x, y) -> angle`)
2. **Accumulation is light.** No stroke is bright; thousands of dim passes make
   the glow. (`alpha 34, count in the thousands`)
3. **The stone decides the palette.** Amber for the seam, slate for the rock;
   nothing else, because the quarry has nothing else.
4. **Every run is a fate.** One seed, one field, forever repeatable — chance is
   allowed exactly once, when a new seed is asked for.

## Intended feeling

Standing in a dark cut of rock, watching heat trace paths a person cannot
predict but the stone has always known.
