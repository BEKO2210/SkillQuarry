Install a skill

no checkout needed

1 · Get the client

One file, standard library only. Nothing else is downloaded.

shell
mkdir -p ~/.local/bin
curl -fsSL https://raw.githubusercontent.com/BEKO2210/SkillQuarry/main/cli/skillquarry.py -o ~/.local/bin/skillquarry
chmod +x ~/.local/bin/skillquarry
export PATH="$HOME/.local/bin:$PATH"   # if it is not already

2 · Point it at this quarry

Any registry of the same shape works — this one, or your own.

shell
export SKILLQUARRY_REGISTRY=https://beko2210.github.io/SkillQuarry/api/v1/skills.json

3 · Install, update, remove

Every install verifies the checksum before the skill’s own installer runs.

shell
skillquarry search
skillquarry install strata --prefix ~/.local
skillquarry update
skillquarry uninstall strata

Prefer a checkout? git clone https://github.com/BEKO2210/SkillQuarry.git and run cli/install.sh. Either way, skillquarry doctor reports what a skill still needs before you install it.

Add your skill

A skill is a directory with a manifest, an agent-facing SKILL.md, tests and a test report. Scaffold one from the reference skill, open a pull request, and CI checks the specification, the checksums and the registry for you.
