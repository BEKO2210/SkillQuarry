LockScope

Hold the lock for as long as you must, and no longer.

Maintained by Belkis Aslani ·

Overview

Detect and repair dangerous Rust lock lifetimes using structured syntax, rust-analyzer semantics, compiler verification and lock-order analysis.

What it does

  • Reads lock acquisitions from a Rust syntax tree, so a multiline or macro-generated acquisition is not missed.
  • Asks rust-analyzer what a value really is: a method named lock() on a plain struct is not a lock.
  • Builds a lock-order graph from acquisitions that genuinely nest, and reports its cycles.
  • Applies exactly one repair — take the lock after the independent await — and lets the compiler and the tests overrule it.

Install

From this quarry, without a checkout:

shell
mkdir -p ~/.local/bin
curl -fsSL https://raw.githubusercontent.com/BEKO2210/SkillQuarry/main/cli/skillquarry.py -o ~/.local/bin/skillquarry
chmod +x ~/.local/bin/skillquarry
export PATH="$HOME/.local/bin:$PATH"   # if it is not already
export SKILLQUARRY_REGISTRY=https://beko2210.github.io/SkillQuarry/api/v1/skills.json

skillquarry info lockscope
skillquarry install lockscope --prefix ~/.local

Installation verifies the checksum in the sidebar before running the skill's own installer. skillquarry uninstall lockscope runs that skill's own uninstaller and needs no checkout either.

From a checkout instead
shell
git clone https://github.com/BEKO2210/SkillQuarry.git
cd SkillQuarry/cli && ./install.sh
skillquarry install lockscope

Quickstart

shell
cd skills/coding/lockscope && ./install.sh

lockscope scan .                 # what is held across an await
lockscope repair . --json out.json
lockscope doctor                 # is this machine able to run it
